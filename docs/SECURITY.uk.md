## Як перевірити, що встановлення в порядку

1. **Завантажуй лише з цього репозиторію на GitHub** (Code → Download ZIP або з [Releases](https://github.com/shadowsh1t/second-brain-kisk/releases)).
2. **Зелена позначка ✅ біля останнього коміту** означає, що автоматична перевірка на чистому Mac на серверах GitHub
   пройшла: контрольні суми, синтаксис, інсталятор (зокрема продовження й захист наявного сховища), шаблон Word,
   черга, перенесення в шаблон, усі чотири мови, відхилення підроблених документів і перевірка, що в репозиторії немає особистих даних.
   Перевірка не використовує сторонніх дій – лише `git` і файли з репозиторію ([.github/workflows/kontrola.yml](../.github/workflows/kontrola.yml)).
3. **Контрольні суми:** у розпакованій папці запусти в Терміналі
   ```bash
   shasum -a 256 -c SHA256SUMS.txt
   ```
   Кожен рядок має закінчуватися `OK`. Інсталятор перевіряє це сам і за розбіжності не запуститься.
   Для певності порівняй і відбиток самого `SHA256SUMS.txt` з тим, що вказаний біля випуску в *Releases*:
   ```bash
   shasum -a 256 SHA256SUMS.txt
   ```
4. **Прочитай інсталятор** – `Instalovat.command` це звичайний текст (відкрий у TextEdit). На початку є перелік
   усього, що він робить.

## Чому macOS попереджає під час запуску

Інсталятор не підписаний сертифікатом Apple Developer (коштує 99 $ на рік). Тому macOS уперше повідомляє,
що файл не вдається перевірити. Замість підпису Apple для перевірки слугують контрольні суми й автоматична перевірка вище.
Як запустити, описано в [README](README.uk.md#-встановлення-в-кілька-кліків).

## Чого інсталятор і система НЕ роблять

- нічого не завантажують з інтернету й нічого не надсилають (кнопки зі ШІ надсилають вміст лише вибраному ШІ, коли їх натиснеш; розширення лише раз на день запитує GitHub про номер останньої версії; оновлення завантажується лише після натискання *Завантажити й встановити*),
- не використовують `sudo` чи права адміністратора,
- не перезаписують наявні файли (копіювання з `--ignore-existing`),
- особисті дані (ім’я, UČO) зберігають лише в `_Systém/nastaveni.json` у твоєму сховищі.

## Захист у системі

- **Дозволи ШІ** (`trezor/.claude/settings.json`): без запиту лише два скрипти системи, `ls` і `date`;
  видалення, завантаження, `sudo`, `ssh`, запуск довільного коду (`python3 -c`, `bash -c`, `obsidian eval`…)
  і читання ключів заборонені; зміни налаштувань, скриптів і доступ до вебу – лише з підтвердженням.
- **Prompt injection:** вміст матеріалів для ШІ – дані, а не інструкції (правила в `trezor/.claude/CLAUDE.md`).
- **Контроль цілісності:** розширення стежить за відбитками скриптів і правил; непідтверджені зміни не виконає. Підтвердити їх можна
  лише у вікні Obsidian, переписавши випадковий код, – не командою.
- **Автоматичне резервне копіювання** копіює лише в папку, яку ти вибереш; видаляти може лише власні папки копій
  (названі датою) і завжди лише після успішного створення нової копії. Дані плагінів із ключами не копіюються.
- **Перенесення документів** відхиляє zip-бомби, посилання за межі документа й непідтримувані вбудовані об’єкти.
- **Мовні пакети** входять до файлів під контролем; під час зміни мови розширення спершу робить резервну копію й записує лише
  системні нотатки всередині сховища (шляхи з `..` відхиляє). Твої власні нотатки й матеріали не змінюються.
- **Оновлення** ніколи не починається саме. Розширення лише читає з GitHub номер останньої версії. Після натискання *Завантажити й встановити* завантажує лише з Releases цього репозиторію й перевіряє контрольну суму ZIP, опубліковану з випуском, контрольні суми всіх файлів і версію; доки не натиснеш **Встановити**, нічого не змінюється, а **Скасувати встановлення** все зупинить. Перед встановленням робиться резервна копія сховища, невдале встановлення повертається саме, а 7 днів доступне **↩️ Скасувати останнє оновлення**. Натискання Встановити підтверджує 🛡 лише для файлів, ідентичних перевіреному пакету. Нотатки, матеріали, `nastaveni.json` і файли, які ти змінив, ніколи не перезаписуються.

Інші помилки та ідеї: **🐞 Повідомити про помилку чи ідею** просто в Obsidian (технічні дані без особистої інформації, усе бачиш перед надсиланням) або через [Issues](https://github.com/shadowsh1t/second-brain-kisk/issues/new/choose).
